# Interactive Data Visualization Dashboard for TB Using D3.js

This project visualizes tuberculosis (TB) data across Indian states using interactive charts built with D3.js. It explores the relationship between TB prevalence and factors like Diabetes, Tobacco, and Alcohol through five distinct visualizations and a unified dashboard.

## 📊 Visualizations

1. **Force-Directed Graph**
   - Network of regions and TB-related metrics
   - Features: search, filter, zoom, export, state saving

2. **Interactive Map Chart**
   - Geographic map of India with pins for states
   - Filters by metric and region, export, search, zoom

3. **Sunburst Chart**
   - Circular hierarchy of TB data
   - Filters, sort, zoom, breadcrumbs, tooltips

4. **Tree Map**
   - Nested rectangles showing TB categories
   - Filtering, sorting, search, and exporting options

5. **Timeline**
   - Animated visualization over time
   - Metric filters, animation controls, region coloring, zoom

6. **Dashboard**
   - Combines all charts in one responsive layout

## 🛠 Technologies Used

- D3.js v7
- HTML5, CSS3
- JavaScript
- html2canvas & Canvg (for exporting charts)
